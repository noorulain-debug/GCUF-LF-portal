# GCUF Lost & Found Portal

## 📌 Project Description
The GCUF Lost & Found Portal is a web-based system designed to help students and faculty report, search, and recover lost items efficiently within the university campus. The system uses AI-based matching to connect lost and found reports automatically.

## 🚀 Features

- User Authentication (Login/Signup)
- Report Lost Items
- Report Found Items
- Image Upload Support
- AI-Based Item Matching System
- Automatic Email Notification for Matches
- Search & Browse Items
---

## 🧠 AI Technology Used

- Hugging Face Sentence Transformers
- Cosine Similarity Algorithm
- NLP-based text embedding
- Weighted scoring system for matching
